# Explore 地面テクスチャ v0.1

2026-11-11。本番用素材の保管先。ゲームへの読み込み・描画の組み込みは別工程。
参考画像は [13357.jpg](../../../../docs/artwork/13357.jpg)。

- `explore-ground-01.png` ～ `explore-ground-20.png`：1024×1024、RGB、PNG、sRGB ICCプロファイル埋め込み。
- `explore-ground-edge-band.png`：共通の外周帯。1024×1024、RGBA、各辺48pxが不透明・内側は透明。
- [manifest.json](manifest.json)：各タイルの説明とSHA-256。
- [validation.json](validation.json)：サイズ・色空間・共通帯・全隣接組み合わせの確認結果。

20枚の外周48pxは画素単位で同一。左右端同士・上下端同士も一致する。
帯は細かいヒビや色むらを含む地肌で、単色の枠ではない。内側は亀裂・走行跡・金属片・汚れの配置を描き分けている。
参考画像からの切り出しやトレースはせず、新たに作画した。緑色のグレーディングは加えていない。

上下左右に隣接させ、まずは回転せず使用する。任意回転した配置は接続保証の対象外。
画像生成ツールの原出力から1024px角の作業画像へ正規化した後、共通帯を合成して書き出している。
生成された納品PNGをそのままコピーしており、保管時の再圧縮・加工はしていない。

検証：20×20の横400通り・縦400通りの境界画素差は0。各タイルの同一画像繰り返しを含む。
混在配置と同一画像の繰り返しを目視確認済み。ゲーム本体での描画・実機確認は未実施。
