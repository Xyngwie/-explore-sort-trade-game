# 貫通弾 v0

状態: 正式仕様（2026-10-24 神宮。実装を実装隊長へ渡す）。設計メモ [`EXPLORE_FACING_AIM_V0.md`](EXPLORE_FACING_AIM_V0.md) §7 と食い違うときは本書を優先する。

## 識別子

- 効果キーは `piercing_round`。画面の語は「貫通弾」。
- 神宮が、貫通弾の実装を実装隊長へ出すよう指示した。保存キーは、その直前に提示した `piercing_round` と画面語「貫通弾」とする。
- HubSave とチェックポイントに、このキー以外の新しい保存キーは足さない。弾は今どおりチェックポイントへ残さない。弾に持たせる貫通率は出撃中の値だけで、名前は保存キーにしない。

## 候補

- 偽盤 2×2〜19×19 の効果キー一覧の末尾に足す。真盤の一覧には入れない。
- 特殊弾の順は `fast_round`、`homing_round`、`emp_round`、`piercing_round`。
- 分類は今の特殊弾。武器カテゴリではない。特殊弾を一つまでとする既存の装備制限に従う。
- 保存済みの `effectKey` は引き直さない。これからキーが付く回路だけが、このキーを引き得る。
- 導通していない回路、効果値 0、1×1、20×20 には付かない。判定は今の回路分類のまま。
- 購入、作成、残骸からの入手は他の特殊弾と同じ経路。新しい値段は作らない。
- 敵の偽盤候補にも入る。敵の行動区分は「距離を取る」（今の `range`）。`fast_round`、`homing_round`、`emp_round` と同じリストへ `piercing_round` を足す。

## どの弾に付くか

- その機体の特殊弾は今どおり一つ。上の順で先に見つかったものだけが、その機体の弾に付く。
- 貫通弾を何枚装備しても効果値は足さない。最初の 1 枚の効果値を使う。探す順は、今の特殊弾が最初の 1 枚を取る順と同じ。
- SMG、散弾、MMR、LMG とは重ねる。その武器の発射数、ばらつき、ダメージ式は変えない。撃った弾に貫通を足す。
- 武器が無く貫通弾だけのときは、通常弾を 1 発撃つ。ばらつきは通常の ±2°。
- 接近戦には付けない。航空支援の威力、費用、冷却、残骸化は変えない。
- 味方の弾も敵の弾も同じ。誤射も同じ。

## 命中

通常ダメージは、今の命中ダメージ（キャンプ軽減と回路の被弾軽減のあと）である。

貫通率は `min(効果値, 50) / 100`。効果値は、その回路が今の分類で既に持っている値を使う。味方は分類結果の effect、敵は敵回路が保持している effect。盤を別に計算し直さない。画面表示の切り捨ては使わない。他の銃の上昇率は使わない。効果値 8 は 8%、100 は 50%、225 は 50%。

装備盾は 1 枚。インベントリの予備盾は防御の層にしない。設計メモの「盾 3 枚」の数値例は使わない。

- 生きている装備盾の、弾に対する今の防御弧（正面 ±60°）へ当たったとき。装甲が受けるのは通常ダメージ × 貫通率。盾が受けるのは通常ダメージ × (1 − 貫通率)。盾の耐久が残っていても、貫通した分は装甲へ入り、それで大破し得る。盾の残り耐久がその分担より小さいときは、盾は 0 になり今どおり消えて交換が始まる。盾の分担の余りは装甲へ足さない。装甲へ入るのは貫通率の分だけ。装甲と盾の減少は丸めない。
- 装備盾が無いとき。交換中や、予備盾だけを持っているときも含む。装甲が受けるのは通常ダメージ × 0.8。
- 同時に飛んだ弾は、今の命中処理の順で 1 発ずつ解決する。先の弾で装備盾が消えたら、続く弾は盾が無いときの 0.8 倍にする。
- 装備盾はあるが弧の外へ当たったとき。80% にはしない。装甲は通常ダメージのまま。盾は減らない。
- 矩形バリケードと地形の障害物は盾ではない。貫通も 0.8 倍も適用しない。

例: 貫通率 50%、通常ダメージ 100、装備盾 1 枚で耐久が足りる。盾が 50 を受け、装甲が 50 を受ける。

例: 同じ条件で盾の耐久が 10。盾は 0 になって消える。装甲は 50。盾が受けきれなかった 40 は装甲へ足さない。

例: 装備盾が無い。装甲は 80。

誤射ログの「−n」は、今と同じく、軽減後で貫通の分配前の通常ダメージを四捨五入した値。文言は変えない。

## 実装の分け方

実装 PR は 1 本。実装隊長は arrow、javelin、tomahawk の一人に `TASK_ASSIGNMENT` を出す。三人には分けない。

触ってよいのは、効果キーの定義とテスト、射撃と命中、敵の行動区分、キーの個数を固定しているテスト、効果キーの一覧を写している契約文書のうちこのキーを足す行。

確認すること:

- 偽盤の末尾が `piercing_round` で、保存済みのキーは変わらない。
- 装備盾 1 枚への分配と、耐久不足でも余りが装甲へ漏れないこと。
- 盾が無いときは 0.8 倍。交換中と予備盾だけもここに含む。弧の外は通常ダメージ。
- 散弾の先の弾で盾が消えたあと、続く弾は 0.8 倍。装甲と盾の減少は丸めない。
- `shieldCircuit.selftest.ts` の「末尾は shield」は、末尾が `piercing_round` になるよう同じ PR で直す。
- 特殊弾は先にあるものが勝つ。貫通弾どうしは足さない。
- 接近戦、航空支援、バリケードのダメージは変わらない。
