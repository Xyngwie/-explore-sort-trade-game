## 1. ひとことで

ディストピアの生活基盤ゲーム。戦闘は目的ではなく **障害**。薄い／敵の少ないエリアを探索して無事に帰る、も正当なプレイ。

---

## 2. ファンタジー

- **生業としてのサバイバル:** 資源を拾い集め、拠点で精製し、機体を直し、次の出撃へつなぐ。
- **戦闘は障害:** 殲滅やスコア稼ぎが主目標ではない。接触コスト・摩耗・弾薬・機体損失が「戦う理由を減らす」側に働く。
- **薄いエリアも有効:** 敵ライトなセクターを回り、コンテナを積んで帰るルートは第一級の正解。無理に前線へ突っ込む義務はない。
- **リスクは選ぶもの:** どこで漁るか（ルート／密度）をプレイヤーが決め、その結果として摩耗と収穫が付いてくる。

### 3.1 Module 1 — explore

- リアルタイムの有人ソート（出撃）。
- サルベージ成果と **機体摩耗** がセットで戻る。
- 僚機は方針で動く: **帯同 / 哨戒 / 回収 / 遊撃**（詳細は `EXPLORE_BEHAVIOR_V0`）。
- 「実入り」（コンテナ／yield の本体）はここに寄せる想定。

### 3.2 Module 2 — sort

- 毎日触る精製レイヤ。薄利でも回数が効く。
- 契約語彙は `SORT_V2` / `YieldBag` を参照（本ビジョンは上書きしない）。

### 3.3 Module 3 — trade

- ハブ。艦隊・在庫・修理／スクラップの拠点。
- 他モジュールからの戻りを受け止め、次の出撃条件を整える。

### 3.4 Module 4 — invade / front（名称 TBD）

- **ドラフト仕様（正）:** [`INVADE_V0.md`](./INVADE_V0.md) — 本節は願望の要約。詳細・受け入れは V0 を見る。
- **Invading Minesweeper** 系譜の任意レイヤ。
- HQ 周辺で **フィールド／ルートを選ぶ**（どこで漁るかの意思決定）。
- 密度スケール案（願望）:
  - Chebyshev 距離 `d`
  - おおよそ `d ~ 10` あたりが前線上限の目安
  - `d >= 12` は壁（進入不可／極端に厳しい境界）
- **毎ループ必須の戦闘ではない。** スキップして quick-battle（または同等の短縮経路）で Module 1 に入れる余地を残す。
- 報酬の主眼は **ルート／インテル／希少ヒント**（実コンテナの二重払いは避ける — §4）。

### 3.5 Module 5 — restore

- **ドラフト仕様（正）:** [`RESTORE_V0.md`](./RESTORE_V0.md) — 本節は願望の要約。`CircuitBoardState` 詳細は V0 を見る。
- `packages/restore`（ひな型）。Slitherlink 風の **回路復元**。
- 高価値なワンオフ成果。日常ループの薄利多売とは別軸。
- 状態例（願望）: Fully Awakened / Bypass / Offline。
- **タイマー圧なし。**
- 軽量セーブ案: `CircuitBoardState` 程度（おおよそ ~0.4KB）。

## 4. ループの指針（願望）

推奨の流れ（強制ではない）:

1. **任意で 4** — ルート／インテルを選ぶ（戦場密度・漁場の意思決定）
2. **1 で実入り** — 有人出撃でサルベージし、摩耗を払う
3. **2 → 3** — 精製し、拠点で修理・次備

短縮経路も正当:

- **ハブ（3）→ 直接 1** を許す（4 を毎回踏ませない）

### 報酬の分割（二重払い禁止）

| レイヤ | 渡してよいもの（願望） | 渡さない／控えめにするもの |
|---|---|---|
| Module 4 | ルート情報・インテル・希少ヒント | 本 salvage と同じコンテナ／yield の二重付与 |
| Module 1 | 実コンテナ・本 yield | （4 で既に渡した「本 salvage」の再払い） |

同じサルベージを 4 と 1 の両方で満額払わない。

## 5. 後段の経済レイヤ（バランス後 — **明示的に後回し**）

バランスが固まるまで実装・仕様化しない。メモのみ:

- 一部物資は **戦闘ゲート付きドロップ**（戦わないと出ない）
