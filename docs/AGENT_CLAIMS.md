# エージェント作業宣言

このファイルは、複数のコーディングエージェントが並行して作業する際に、各エージェントの「誰が・何を・何の目的で」変更しているかをGitHub上に明示するための作業台帳です。

- **役割:** 実行隊長
- **担当:** 小〜中規模の実装、CI/ビルド障害の修正、既存タスクの分割、PR作成、Actions確認、マージ後Deploy確認。

- **完了PR:** #191 / merge commit `4d7fcf867535a50b6877f22681b7f8f5e773549f`

## 並行作業の原則
- 各エージェントは作業開始前に、このファイルまたはGitHub上のPR本文・Issueで自身の役割、目的、変更範囲を宣言する。
- 他エージェントの宣言済み範囲を勝手に奪わない。
- 競合しそうな変更は、既存PR・Issue・この台帳を確認してから着手する。
- CIが意図の混在を理由に停止した場合、コードを無理に通すのではなく、まず作業目的と変更範囲をGitHub上で明確化する。
