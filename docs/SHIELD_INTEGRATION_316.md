## R316-01：未開放の屹立ボタンが見える

現行mainのローカルと公開版で再現。P盾/装備盾がない状態で出撃すると、「屹立」ボタンに`hidden=true`があるのに、既存のボタン/行レイアウトのdisplay指定で表示されていた。390pxで幅約49.97・高さ35.38、computed displayはflex。実行ロジックは拒否するため不正に盾を設置はできないが、#315の「不適格時は非表示または無効」の承認条件に反する（この場合は表示され有効に見える）。

変更は`style.css`の`#btn-barricade[hidden] { display: none; }`のみ。通常ボタンや他のhidden要素を広く変更しない。修正後ローカルはdisplay:none、矩形0×0。新しいゲーム仕様ではない。

既存の実操作テストへ、P盾なし（盾なし/拾得後）、P盾あり装備盾なし（設置後）、自身のP盾＋盾再装備の可視性を追加した。属性だけでなくPlaywrightの`isHidden/isVisible`で描画状態を確認する。公開版は未デプロイなので不具合が残ることを再確認し、修正済みと扱わない。
