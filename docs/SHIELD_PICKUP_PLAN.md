## 確定済みの契約

仕様台帳第2章・Q41–43・Q162–174に従う。

- 装備1枚、予備は容量が許す範囲。盾はすべて重量1。
- 地面の拾得は機体1体長以内。移動・回避・被弾で直ちには止めず、距離外や機体破壊で中止。地面盾は元の位置、進捗破棄、再指示で最初から2秒。
- 開始時と完了時の容量確認。容量は予約せず、完了時満杯なら他の荷物を投棄しない。失敗後の自動再試行なし。
- 容量失敗は「インベントリ満杯：盾を回収できませんでした」の短い通知と戦闘ログ1件。
- 同一盾は排他。競合時は「この盾は別の機体が回収中です」の通知のみ。横取り・待機・自動再試行なし。
- 地面の一覧は現在HP降順→最大HP昇順→生成順の古い順。表示は現在/最大HP。
- 盾破壊時の予備選択は現在HP降順→最大HP昇順→取得順の古い順。交換2秒は無防備で、交換対象は開始時に固定し予約する。
- 交換対象は完了まで手動投棄・移動・別用途に使えない。死亡時は交換中止、装備・交換中・予備をHP/ID保持で地面へ落とす。
- 地面の集約表示は「盾 ×3（回収中1）」形式。すべて予約中の場合だけ半透明。
- ブラウザー内の処理順による排他であり、Q175–177のサーバー原子的受理・通信切断中処理を実現したとは報告しない。
