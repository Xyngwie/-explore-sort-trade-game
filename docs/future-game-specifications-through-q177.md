## 2. 既知のゲーム全体仕様（Q1～110の詳細履歴は未照合）

- EXPLOREは1対1のリアルタイム探索を想定。広く疎な戦場、資源の集積地点、散在する機体残骸があり、通常移動は約600秒を想定。現在の180秒EXPLOREを変更した実装は未確認。
- INVADEとEXPLOREは同じ戦場全体を利用する。INVADEには任意のマインスイーパー型偵察があり、敵配置を地雷、周辺敵占有数を数字として扱う。偵察後に敵が移動し得る。
- 戦場の残骸は剥離完了まで消滅せず、移動・弾丸を妨げず遮蔽物にもならない。残骸の回路をフィールドで取り出すことはできず、残骸をHUBに持ち帰る必要がある。
- 残骸の装甲剥離：残骸1個から盾1個。8秒間静止して作業し、途中進捗は残骸側に保存され再開可能、作業予約は排他。完了時に残骸と残存回路を除去し、失われた回路のサイズ・効力および残骸機体の学習価値を記録し、地面に盾を生成する。警告表示はしない。
- 盾の最大耐久値 = 50 + 剥離機体の盾回路効力。盾回路なしでも装備・使用可能。盾の重量は1。
- 盾は正面±60°（計120°）を防御する。遮蔽・回路軽減後の被ダメージを受け、命中時に盾耐久値が正なら超過分も含めその一撃は盾で完全吸収し装甲に貫通しない。耐久値0で盾は消滅。
- 機体の装備盾は1個。予備盾はインベントリ容量の範囲内で個数無制限（Q162）。装備・拾得は2秒、地面の拾得距離は機体1体長以内。移動・回避は可能、距離外への移動で回収中止。投棄は即時で耐久値保持。
- 地面の盾は同一戦場の遠征をまたいで残存し、戦場再生成時に消える。移動・弾丸を妨げず遮蔽にならず、同一座標に重ねられる。集約表示例「盾 ×3（回収中1）」、すべて予約中のときのみ半透明。選択一覧に現在/最大HPを表示。現在HP降順→最大HP昇順→生成順（古い順）。
- 盾の破壊時に予備があれば自動交換を2秒行い、交換中は無防備。機体破壊時は残っている装備盾・交換中の盾・予備盾を耐久値保持で地面に落とす。
- 盾と残骸の細かな操作競合・剥離・搬送・攻撃・回避の条件について、Q1～110の原文との照合が必要。
