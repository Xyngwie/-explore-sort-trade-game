# docs/handoff — 引き継ぎ仕様

このフォルダのファイルは、新しく参加する AI エージェントのチームに渡す引き継ぎ仕様です（機械で読める JSON）。

- ここに書かれた決定は、プロダクトオーナーの神宮が決めたもので、すべて確定です。変えないでください。
- エージェントが決めてよいのは、内部の技術的な細部（データの持ち方、関数名、アルゴリズムなど）だけです。
- 遊びの細かい仕様や見た目の仕様を、エージェントが自分で決めてはいけません。
- 決まっていないこと（`open_questions` や、仕様にない細部）は、実装の前に神宮に聞いてください。1 回に 1 問ずつ、選択肢（A/B/C）とおすすめ、その理由を付けます。
- 画面の文字は日本語です。「抽出」ではなく「帰還」を使います。
- CI を緑にし、squash でマージし、main の Deploy Modules Preview が成功することを確かめます。セルフテストを足し、途中保存とセーブの互換を保ちます。
