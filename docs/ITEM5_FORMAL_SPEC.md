### 5-1（#241）

出撃中にやられた機体は、どの終わり方でも格納庫で大破になる。できるのは解体だけで、回路は残骸と一緒にある。一律摩耗（帰還 15、撤退 20、失敗 35）は、生き残って帰った機体だけにかかる。

### 5-1b（#242、#243、#244）

撃破された機体（隊長も）は、撃破した場所に回路ごと残骸として残る。回路だけを抜く行動は戦場にない。回路単体の積載量は決めない。背負うときの残骸の負荷 2 は、背負い（項目4）まで使わない。

- 回収していない残骸は格納庫の機体一覧から外す。格納庫には「残骸 n 機（Invade の盤に表示）」だけ出す。保存は `lostMechs` に、置き去りとの区別（`kind`）、マス、Explore の座標（`pos`）を足してある。
- 離昇のとき搭乗円の中にあれば回収する。回収した残骸は大破のまま、回路を付けたまま戻る。修理はお金の PR まで解体だけ。解体すると回路は倉庫へ戻る。
- 盤を作り直すと残骸は回路ごと消える（W3 の C）。それまでは同じマスの同じ座標に再び現れる。
- Invade を通らない出撃の残骸は、機体も回路も失う。
- 残骸の中の回路は、部隊の回路の数とボーナスに数えない。
- マップは灰色の機体に「残骸 僚機A」。Invade の印は右下の錆色の点。
- 摩耗だけで耐久 0 になった機体は、格納庫に大破のまま、回路を付けたまま戻る。
- 古いセーブの、回路だけの落とし物（`wreck_not_carried`）は、読むときに倉庫へ戻す。
- #241 の公開時点では回路が外れて落とし物になる古い形だった。元には戻さず、5-1b で置き換えてある。W0 のやり直しはしない。

### 5-2（#245）で入っているもの

- 隊長機が大破しても、その場で失敗にしない。出撃は続く。
- カメラは残骸に留まる。隊長の移動と射撃は効かない。僚機への命令は出せる。
- 大破したあとに新しい帰還要請は出せない。大破より前に出した搭乗円は消えない。隊長の残骸が円の中で離昇すれば、無料の通常の帰還になる。見出しは「帰還成功（隊長の残骸を回収）」。救助費用の行は出さない。円の中の僚機、残骸、コンテナも回収する。

## 項目5-2b（これを実装する）

撤退は隊長機の大破後だけにする。時間切れでは、大破していても生きていても、強制救助が来る。制限時間は 180 秒のまま。

### 撤退ボタン

隊長が無事なあいだはボタンを出さない。大破した瞬間に出す。押したら確認を出し、撤退するかやめるかを選ばせる。文言は上の正本のとおり。やめるなら出撃は続く。

ボタンの救助撤退（時間切れより前）は、今の 5-2 のまま。費用は所持金の半分。積荷とキャンプの置場は失う。生きている僚機は置き去り。

### 時間切れの中心と、進行中の搭乗円

中心は、搭乗円が出ていればその中心、出ていなければ隊長機。半径は今の帰還円と同じ（`boardingRadius` は 110）。

時間切れの瞬間に搭乗円が進行中なら、その円の完了を待って、通常の帰還として決着する。待つ間は移動と積み下ろしができない。この帰還は今の無料の通常帰還（`extract`、生き残って帰った機体の摩耗 15、救助費用なし）で、見出しは状況に合わせて今の帰還の見出しを使う。隊長の残骸が円の中なら「帰還成功（隊長の残骸を回収）」。

円が無いときの時間切れは、下の「生きている」か「大破している」かで分かれる。

### 隊長が生きている時間切れ

お金はかからない。`rescueFee` は付けない（0 を送っても、Hub は 0 を引かない）。

半径の中にあるものを持ち帰る。

- 生きている僚機。回路が無くても帰る。
- 残骸。回収した残骸は、今の回収と同じく大破のまま回路付きで戻る。
- まだ拾っていないコンテナ。

半径の外は次のとおり。

- 生きている僚機は置き去り。
- 残骸は残る。盤を作り直すと消える。Invade を通らない出撃では回路ごと失う。
- 積荷は失う。
- キャンプの置場は、中なら持ち帰り、外なら失う。

生き残って帰った機体の一律摩耗は 20。既存の種別で 20 になるのは撤退（`abort`）だけなので、`returnKind` は `abort` にする。`extracted` を立てて帰還（`extract`、摩耗 15）にしない。

`abort` だからといって、半径の中のコンテナを 0 にしない。今の `toExploreResult` は帰還していないと積荷を 0 にする。この戻りだけは、半径の中のコンテナを Explore から Sort への今の受け渡しで倉庫へ戻す。新しい識別子は作らない。

### 隊長が大破している時間切れ

搭乗円が進行中なら、上のとおり円の完了を待って通常の帰還にする。それ以外は、半径での回収をしない。今の救助撤退と同じ喪失にする。

- 積荷を失う。
- キャンプの置場を失う。
- 生きている僚機は置き去り。
- 残骸は回路ごとその場に残る。盤を作り直すと消える。

引く金額だけが違う。`floor(所持金 × 3 / 4)` を `rescueFee` に載せる。残りは所持金からその額を引いた分。0c は 0c。501c なら 375c を引き、126c が残る。`sortieId` ごとに 1 回。所持金は 0 より小さくしない。経路は今の撤退（`abort`）。

### 見せ方

- 残り 30 秒で時間の数字を赤くし、帯「あと30秒で強制救助」を出す。10 秒からは数字を大きくする。
- 警告のあと、救助の中心のまわりに薄い円を出す。色は搭乗円と違う色。正本に色の指定は無い。実装が色を選び、PR にその色を書く。
- 大破中の帯「隊長機大破 — 撤退できます（救助費用：所持金の半分）」はそのまま残し、2 行目に小さく「時間切れまで待つと、救助費用は所持金の¾」と出す。
- 時間切れになったら、そのまま結果画面へ進む。操作を続ける状態は作らない。
- ログは 1 行。「時間切れ。強制救助。」
- 今の「時間切れ」の帯、「時間切れ・帰還要請不可」のボタン、キャンプ防衛モード、時間切れのあとの操作ロックはなくす。
- Invade の強制戦闘も、同じ時間切れにする。

## 決定済みだが、この PR では実装しない

### 5-3（戻ると途中保存）

出撃中のブラウザの戻る、および Android の戻るジェスチャーは、確認を出さずに無効にする。昔の「戦線復帰／撤退」の確認は作らない。戻るで撤退したときの罰も作らない。タブやアプリを閉じたとき、ほかのアプリへ切り替えたとき、電池切れのときは止められない。

画面が隠れたとき、およびページを離れたときは、自動で一時停止する。180 秒の時計も止める。出撃の途中を保存し、開き直したら切れた時点から続ける。書き込みは別のキーに書き、読み直してから指す先を切り替える。版を付ける。HubSave には触らない。読めない途中保存は捨てて HUB へ戻る。テストは、書き込みが途中で切れても今のセーブが残ること、古いセーブが読めること、復元が元と同じであること。

開き直した画面は出撃のままにし、「一時停止中 — タップで再開」と出す。ほかのアプリから戻って画面が見えても、タップするまで一時停止のまま。途中保存のある出撃を格納庫から放棄するボタンは作らない。再開して、出撃の中で帰還か撤退をして終わらせる。

### 真盤

「4」の 1×1 回路は、僚機が動けるようになる回路と同じものである。付けると僚機が動ける。最初の周回は実質単機でクリアする。

Invade を初めてクリアして、この回路を発見するまでは、作成、購入、探索で拾う回路、敵が落とす回路のすべてで、真盤の確率を 0% にする。発見したあとの作成は、購入と同じ 1% にする。

今あるセーブに初クリアの記録が無いものは、まだクリアしていない扱いにする。盤の様子からクリア済みとは推測しない。

Restore は 1×1 に対応させる。この回路は、最初から直った状態では渡さない。
