## 8. PR2b HUD 補給・売買パレット（神宮 2026-11-01 決定）
HUD の 弾・装・電・Cr をタップすると補給・売買パレットが開く。箱タップは今までどおり SORT（DOCK `#unopened-panel`）。価格・セーブ形式は変えない（売 5c／買 6c、箱 15c）。
1. 表示はボトムシート。✕・外側タップ・下スワイプで閉じる。取引後も開いたまま。
2. 行は 弾・装・電・ジャンク（ジャンクは HUD には出さない）、それに箱の購入。Cr タップでも同じパレットが開く（タップした行を強調）。
3. 操作は購入と売却だけ。艦隊補給ボタンは置かない。動くのは在庫の合計だけで、機体に積んだ弾は変えない。
4. Cr が足りないボタンは無効にし、「要 Xc / 持 Yc」を出す。在庫 0 の売却は無効にし、「在庫なし」を出す。
5. 売却は毎回確認する。DOCK の `#four-resource-trade` カードの売却にも同じ確認を付ける（カードのほかの部分は PR4 まで変えない）。
6. 新規ゲームの導入中も使える。使えないのは explore と SORT 受け渡し中（HUD タップと同じく無効）。
7. 価格は「買 6c / 売 5c」と表示する。取引後の増減は #300 の色と記号（+緑・−赤・±0灰）。
8. ページを再読み込みせず、その場で更新する。取引関数は DOCK と同じもの（`resource-trade.ts`）を使い、1回の取引で保存は1回。プレイログには `resource.buy|sell`／`unopened.buy` と数量を記録する。DOCK は `wreckline:palette-trade` を受けて、メモリ上のハブを保存から読み直す。
9. 長押し（決定。定数 `HOLD_*`）：
   - 押し始めて 0.4 秒で長押しになり、0.1 秒ごとに 1 段増える。1 段 10 刻みで 1…10 → 20…100 → 200…1000 → …。
   - 長押しは数量を増やすだけ。指を離すとその数量で 1 回取引する（売却は確認が出る）。
   - 指をボタンの外へずらすと取り消し。
   - 最大（Cr で買える数／売れる在庫）で止まり、「最大」を表示して枠を 1 回光らせる。
   - 押している間は、ボタンの上に「×N　合計 ±Xc」を出す。
   - 短く押すと 1 個。最大が 0 のボタンは長押しも効かず、要／持を表示する。

## 14. 下部タブが反応しない不具合（PC テスト run-20261101-pc-fullscreen-shell-001）
- 原因：INVADE の固定出撃バー（`.cell-sortie-bar`、`position:fixed`・z-index 1000・画面下 0.75rem）がタブ列の上に重なり、バーの無い隙間（中央付近）だけタップが届いていた。explore のトースト（固定・下 1.4rem）も同じ位置。
- 修正：タブ列を `position:relative; z-index:1001`（ページ内容より上、パレット・記録パネル等 9000 以上より下）。タブ表示中は `--wl-shell-tabs-h`（56px）を出し、INVADE の出撃バーと explore のトーストはその分だけ上にずらす。
- 回帰検証：`scripts/verify-shell-tabs-tap.cjs`（DOCK／RESTORE／INVADE／explore ブリーフィングで全タブの端まで当たり判定、INVADE で端タップ→DOCK 遷移、出撃バーがタブより上、セーブ・チェックポイント保持。PC／スマホ）。
