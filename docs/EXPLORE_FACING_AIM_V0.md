# EXPLORE 機体の向き・銃口・射撃AI・残骸盾・貫通弾 v0

状態: 設計承認済み（2026-10-16 神宮）。実装の Go は 2026-10-17 に出た（§8 の順番で進める）。 内部の技術的な詳細（角度の基準、学習データの保存形式、射撃口の寸法など）は開発が決める。

## 1. 向きと旋回
- 向きは移動方向とは独立。後退、横移動、その場での旋回ができる。旋回には時間がかかる（瞬間旋回はしない）。
- 普段は移動方向を向く。戦闘中は、攻撃できそうな敵のほうへ旋回する。
- 目標は「旋回すれば撃てるか」で選ぶ。今の射界にいる敵だけを候補にしない。プレイヤーの明示的な指示を優先する。
- 旋回は **決定**: 移動中も停止中も 90°/秒（真後ろまで約 2 秒）。重い積載は、移動が遅くなるのと同じ比率で旋回も遅くする。旋回は活動量を使わない。
- 旋回中も移動・視界・盾の向きを更新する。撃てるかどうかは、今の銃口の向きで判定する。
- 角度は 0〜360° で扱う。相対角は符号付きの差に正規化し、「|相対角| ≤ 半分の弧」で判定する。
  - 例: 2° は射界の外だが正面視界の中。45° は周辺視界の中で盾の中。100° は周辺視界の中で盾の外。170° はどれにも入らない。

- 出撃地点（2026-10-17 決定）: 地図の中央 (700, 500) に移す（元は左端の中ほど (180, 500)）。
  - 隊長機は出撃地点にいて、画面の上を向く。
  - 僚機は出撃地点を囲む輪に等間隔に並び、それぞれ外を向く。
  - 敵は今と同じ距離で、四方から来る。敵は最寄りの味方を向く。
  - 最初のカメラは出撃地点に合わせる。障害物を置かない半径（170）とコンテナを置かない半径（140）は今のまま。時間などの数値は変えない。
  - 古い固定の帰還地点 `extract` も中央へ移す。
  - 置き去りの機体と回路は、出撃地点の周りで待たずに戦場のどこかに置き、探しに行く形にする（決定済み、詳細は未決定で別 PR）。それまでは今のまま、出撃地点（中央）の周りで待つ。
- 積載 6（移動の速さ 0）では旋回も 0 になり、正面にいない敵は撃てない（2026-10-17 決定、そのまま）。
- 近接攻撃は、射界 3° ではなく周辺の 270°（±135°）の中なら使える（2026-10-17 決定）。
- 僚機の編隊は、隊長機の向きではなく移動方向を基準にする（2026-10-17 決定）。
- 世界観: 移動の仕組みは直径 15m の球体で、中に履帯が 2 本ある。これは世界観だけの設定で、機体の大きさと当たり判定は変えない。

## 2. 視界
- 正面 60° は遠距離用で、見える距離は約 2 倍。周辺 270° は近距離用で、見える距離は通常どおり。背後の 90° は死角。
- 障害物の向こうは見えない。高さ方向の判定はしない（例外は航空支援で、盾を素通りする）。
- 味方のどれかが見ている敵は、正確な位置をリアルタイムで全員が共有する。自分の視界の外でも狙える。見失ったら、最後に見た位置を約 5 秒だけ地図に残す。
- 敵も、向き・旋回・視界・射界 3° について味方と同じルールに従う。

- PR2 の決定（2026-10-17、すべて A）:
  - 周辺 270° は正面を含み、背後 90° が死角。
  - 霧（探索の格子）は視界の形に合わせて晴れる。コンテナの発見と補給物資の表示も、同じ視界で判定する。
  - 見失った敵は、最後の位置に赤い輪郭だけの円を出し、5 秒かけて薄くして消す。
  - 味方全機の視界の扇形を、ごく薄く地図に描く。
  - 視線を遮るのは障害物だけ（残骸・コンテナ・機体は遮らない）。
  - 敵どうしは視界を共有しない。
  - 僚機は、仲間が見ている敵が射程内にいれば、旋回して撃つ。命令が無ければ追いかけない（追うのは自分で見えている敵だけ）。
  - 視界を広げる回路は、正面と周辺の両方に同じ倍率をかける。
- 分隊の知識（2026-10-17）: 見えている敵、5 秒残る最後の位置、発見済みのコンテナを 1 か所にまとめ、AI はそこを読んで決める。

## 3. 銃口・射界・命中
- 銃口は正面に固定。射界は 3°（片側 1.5°）。砲塔は回らず、機体ごと旋回して狙う。
- 射界 3°・視界 60°・盾 120° は別のもの。混同しない。
- 命中は、実際に飛ぶ弾で決める（AI の判断だけで命中を決めない）。弾は誰にでも当たる。
  - 敵の弾は、他の敵にも敵の盾にも当たる。味方の弾は味方にも当たる。
  - 「敵の弾は味方にしか当たらない」今のコードは直す。

## 4. 誤射
- 誤射は状況で判断する。味方がいるだけでは射撃を禁止しない。
- 考えるもの: 射線上にいる味方の位置と半径、距離、弾道、命中確率、予想される損害、弾薬の残り、戦術的な価値。
- ML の導入後は、危険と射撃の価値を比べる。最初は誤射をほとんど気にしなくてよい。実際に起きた誤射から学ぶ。
- それまでは中間の設定にする。危険が小さければ撃ち、そうでなければ横に動いて射線を空ける。
- 射撃の流れ: 敵の情報を得る → 候補を評価する → 旋回する → 3° 以内か確かめる → 誤射の危険を評価する → 撃つ・待つ・位置を変える → 弾が飛ぶ → 結果を記録する → 機体ごとに学ぶ。
- 学習（将来のフェーズ）:
  - 機体ごと（OwnedMech.instanceId）に、出撃をまたいで保存する。
  - 結果の分類: ENEMY_HIT / MISS / FRIENDLY_HIT / OBSTACLE_HIT / SHIELD_BLOCK / ARMOR_DAMAGE / SUCCESSFUL_EVASION / FAILED_EVASION。
  - 機体ごとの癖を残し、ひとつの最適解にまとめない。他の機体の経験を丸ごと写さない。
  - 回路を外したら、その回路だけの能力は残さない。

## 5. 運ばれている機体
- 運ばれている機体は、運ぶ機体とは別に、自分の銃口で狙う。射界は自分の正面から 3°、旋回は自分で 90°/秒。
- 機体は、積まれるときに持ち物をすべて落とす。そのため、運ばれている機体は盾を持てない。
- 積載が 3 以上の機体なら、機体と盾を同時に運べる。

## 6. 残骸盾
- 正面に固定した一体の盾で、範囲は ±60°（120°）。武器は射撃口から撃つ。高さ方向は守らないので、航空支援は直接当たる。
- 盾の範囲内の被弾は、先に盾の耐久を減らす。装甲は HUB でしか直せない。
  - 盾が壊れる 1 発は、あふれた分も含めて盾がすべて受ける。壊れた盾は消え、何も残さない。
- 作り方:
  - 出撃時には持っていない。戦場の残骸から作る。使える残骸の種類は問わない（僚機の残骸も使える）。
  - その場で 8 秒止まると完成する。作っている間は撃てない。
  - 作っている間に動くか撃たれたら中断し、残骸はそのまま残る。
  - 作ると残骸とその回路は使い切りになる。
- 喪失の記録:
  - 失った回路の効果と大きさ、その機体の戦歴（撃破数・出撃回数）を記録する。
  - 帰還の結果画面と、格納庫の一覧に出す。
- 耐久: 元の機体の最大耐久の 50%。
- 積載: 盾 1 枚が積載 1 を使い、重さの分だけ移動が遅くなる。残りの枠で回収ができる。
- 直し方: 別の残骸から作り直す。そのたびに回路を失い、記録する。戦場にガラクタは残らない。
- 帰還時に外し、持ち帰らない。
- 使えるのは、「残骸盾」コマンドを解放する回路を持つ機体だけ。敵も味方も同じ。回路が無ければボタンも出さない。
- 回路の効果値: 効果値 % の分だけ、盾の重さで遅くなる分を減らす。耐久には上乗せしない。
- 重ね持ち:
  - 「残骸盾」の回路の枚数まで盾を持てる。1 枚ごとに積載 1 を使う。
  - 外側の盾から削れる。
- 表示: 機体のカードに「盾 32/50」と出す。地図では機体の前に弧を描き、盾が減るほど薄くする。
- 敵も残骸から盾を作る。2026-10-14 の敵の補給の決定とは矛盾しない（神宮の判断）。
- 回路の分類: 「その場を守る」。新しいキーは最後に足し、保存済みの回路は引き直さない。
- 世界観: EM シールドが守るのは操縦席だけで、電力は無限、資源は使わない。

## 7. 貫通弾（4 つ目の特殊弾）
- 盾に当たると、ダメージの「効果値 %」が盾を抜けて装甲に入り、残りを盾が受ける。効果値はそのままの値で、上限は 50%。
- 盾が何枚もあるときは、1 枚ごとに同じ貫通率で抜けていく。
  - 例: 貫通 50%、ダメージ 100、盾 3 枚 → 盾が 50・25・12.5 を受け、装甲に 12.5 入る。
- 盾の無い相手には、通常の約 80% のダメージ。
- 貫通弾の回路は重ねても強くならない。
- 手に入れ方は他の特殊弾と同じ（残骸の回路、または購入）。
- 回路の分類: 「距離を取る」。新しいキーは最後に足し、保存済みの回路は引き直さない。
