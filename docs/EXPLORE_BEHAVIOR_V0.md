**ステータス:** 採用方針（2026-09-17）・実装は `packages/explore` 垂直スライス  
**正本:** 本 GitHub モノレポの `packages/explore` と本ドキュメント  
**レガシー:** 旧 `.grok.me` Module1（WRECKLINE プレビュー）は **練習用／退役**。URL・Export をソース正本にしない。ゲームプレイ意図のみ参照可。

## 1. ひとことで

隊長は直接操作、僚機は **方針（スタンス）** で動く。回収完了後は自動で帯同に戻り、哨戒は拠点まわりを巡回し、遊撃は地点指定なしの自律攻撃。コンテナは探索で見つかるまで不明。画面外の僚機にも命令でき、画面外戦闘は戦報ログに出る。

隊長の移動・命令はプレイヤー主導のまま、**射程内の脅威には自動で反応射撃**する（僚機の帯同反応射撃と同系）。Space/F でも明示射撃できる。

隊長は **発見済み・未回収のコンテナ** に `interactRadius` 内で接触しているあいだ、回収チャネルを **自動で開始／継続**する（E キーは任意の明示インタラクトで、必須ではない）。僚機の `recover` 方針による回収は従来どおり。

## 2. 僚機方針（policies）

| ID | 表示 | 意図 | 地点 UI |
|---|---|---|---|
| `escort` | 帯同 | 隊長の左右後方にフォーメーション追従。近接脅威には反応射撃 | 不要（即時適用） |
| `patrol` | 哨戒 | **目標（ウェイポイント）または隊長** を中心に軌道／セクター掃討。直線で変な点へ飛んでから目的地、という挙動にしない | 任意（省略時は隊長周辺） |
| `recover` | 回収 | 発見済みコンテナへ向かいチャネル回収。完了後は **自動で帯同** | 省略時は最寄り発見コンテナ |
| `raid` | 遊撃 | 敵へ自律接近・交戦。弾薬浪費寄りでよい | **禁止**（クリック目標なし） |

### 2.1 回収 → 自動帯同

回収チャネルが完了した僚機は、同じティックで:

1. `stance = escort`
2. `waypoint = null`
3. 戦術ログに「回収完了 → 帯同」を残す

プレイヤーが再指示するまで帯同を維持する。

### 2.2 哨戒の一貫性

- 中心 = `waypoint ?? leader.pos`
- 移動目標は中心まわりの **軌道点**（角度を進める）。到達のたびに次の軌道点へ
- 交戦レンジ内の敵には一時的に反応してよいが、哨戒中心から大きく離脱し続けない

### 2.3 遊撃（地点指定なし）

- 命令パネル／ラジアルで遊撃を選んだ瞬間に適用
- マップクリックで遊撃地点を取らない
- AI は視界／広域で最寄り生存敵を狩り、敵なし時は隊長周辺をうろつく

---

## 3. 発見フォグ（コンテナ）

- ワールドにコンテナは最初から存在するが、**隊長または僚機の視界に入るまで位置不明**
- UI: 未発見はマーカーなし（または「未知信号」程度の曖昧表示は任意）。発見後に確定アイコン
- 回収命令の自動ターゲットは **発見済み** のみ

---

## 4. オフスクリーン指揮

- 僚機がカメラ外でも、常時表示の僚機パネルから方針を出せる（召還／帯同／哨戒／回収／遊撃）
- 「召還」= 帯同のエイリアス（隊長へ戻れ）
- マップ上の長押しラジアルは任意。v0 ではパネル命令で足りる

---

## 5. 画面外戦闘 → 戦報

- 戦闘イベント（与ダメージ／撃破／被弾）の発生位置がビューポート外のとき、**戦報フィード**へ要約行を追加
- 画面内は既存の軽いログ／エフェクトでよい
- フィードは新しい行が上（または下）に積み、直近 N 行を保持

例: `戦報: 僚機A が敵を撃破（北東・画面外）`

---

## 5.1 抽出／搭乗フェーズ（boarding extract）

固定 EXTRACT 地点上の即時脱出ボタンは **廃止**。隊長は出撃中 **どこからでも** 抽出を要請できる。

| 段階 | タイミング | 挙動 |
|---|---|---|
| 要請 | ボタンまたは `X` | 要請時点の隊長位置を中心に **搭乗円**（半径 `BALANCE.boardingRadius`）を展開。生存僚機へ自動で **哨戒**（waypoint = 円中心）。進行中の再要請・キャンセルは v0 では不可 |
| 貨物 | 要請から `boardingCargoDelaySec`（既定 **10s**） | `cargoArrived` フラグ + 戦術ログ（任意の視覚） |
| 離昇 | 要請から `boardingLiftOffDelaySec`（既定 **15s**） | 円内の生存友軍を回収。円外の生存友軍は **置き去り**（ログに名前）。**隊長が円内なら出撃成功**（サルベージは現状どおり保持）。隊長が円外なら `extract_missed` で失敗（サルベージ没収） |

HUD は貨物 ETA／離昇 ETA とマップ上の搭乗円を表示する。

定数は `packages/explore/src/game/balance.ts` の `boardingRadius` / `boardingCargoDelaySec` / `boardingLiftOffDelaySec`。

## 5.2 invade → explore セクター密度（脅威）

invade で選んだセクターは `sectorX` / `sectorY` / `density` / `intelFlags?` として explore に渡る（`parseInvadeToExploreSearch` · `HANDOFF_M45_V0`）。

| 項目 | 挙動 |
|---|---|
| 取込 | 起動時にパースしブリーフィング表にセクター・density・脅威要約を表示 |
| 脅威 | `density` 0..1 で敵数・スポーン距離・敵速度を線形補間（`BALANCE` の `densityEnemy*` / `threatFromDensity`） |
| strip | 取込後に `stripHandoffParams(..., HANDOFF_QUERY_KEYS.invadeToExplore)` でクエリ削除 |
| 無し | セクター無し時は基準敵数（`baselineEnemyCount`）・基準距離・速度×1 |

定数は `packages/explore/src/game/balance.ts`。trade→explore の配備キーとは衝突しない。

## 5.3 invade → explore 交戦ハンドオフ（forced / raid）

invade マインスイーパから探索へ渡す戦闘モード。キー契約は invade PR / `HANDOFF_M45_V0` / `@estg/shared` と揃える。

| キー | 値 | 意味 |
|---|---|---|
| `engage` | `forced` \| `raid` | 強制（地雷踏み） / 任意（旗セル） |
| `enemyCells` | `sx,sy;sx,sy;...` | 戦闘に引き込む敵／地雷セル（`encodeEnemyCells`） |

| engage | ブリーフィング表示 | 敵スポーン |
|---|---|---|
| `forced` | **強制交戦・周囲引き込み** | より多く／硬く（`enemyCells` 件数＝当該＋隣接。無いときは density＋neighborCount 相当） |
| `raid` | **任意侵入** | 少なく集中（旗セル 1 件中心） |
| （無し） | — | 従来どおり density のみで脅威スケール |

取込後は `HANDOFF_QUERY_KEYS.invadeToExplore`（`engage` / `enemyCells` 含む）を strip。invade 盤 UI は触らない（並列）。

実装: `threatFromInvadeSector` / `ENGAGE_BRIEFING_LABEL`（`packages/explore/src/game/balance.ts`）。

## 8. 受け入れ（Behavior v0）

1. 回収完了後、当該僚機の方針が自動で **帯同** になる（ログまたはデバッグ表示で確認可）
2. 哨戒中の移動目標が中心周辺の軌道上にあり、意味のない単発直線ワープに見えない
3. 遊撃適用にマップクリック／地点指定が不要。適用直後から敵探索・交戦する
4. 僚機が画面外でもパネルから命令でき、スタンスが実際に変わる
5. 未発見コンテナはマップ上に確定位置を出さない。発見後に表示・回収対象になる
6. 画面外で戦闘が起きると戦報フィードに行が増える
7. `npm run typecheck` / explore selftest が通る。`npm run dev:explore` で垂直スライスが動く
8. 隊長は Space/F を押さなくても、武器射程内の敵に自動反応射撃する（移動はプレイヤー操作のまま）
9. 抽出はどこからでも要請でき、搭乗円・僚機自動哨戒・貨物 10s／離昇 15s の位相どおり動く。離昇時に隊長が円内なら成功、円外僚機は置き去りログ。隊長円外なら失敗
10. 隊長は発見済みコンテナに接触していれば E を押さなくても回収チャネルが進み、時間経過で回収完了する
11. invade→explore の `sectorX`/`sectorY`/`density` を取込み、ブリーフィングに表示し、density で敵数・スポーン距離・敵速度が変わる。取込後に当該クエリを strip する
12. `engage=forced` でブリーフィングに「強制交戦・周囲引き込み」を出し、`enemyCells`（または density＋neighbor 相当）に応じてより多い／硬い敵をスポーンする。`engage=raid` では「任意侵入」と少数集中スポーン
