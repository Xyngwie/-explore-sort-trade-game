**ステータス:** 採用方針（2026-09-17）・実装は `packages/explore` 垂直スライス  
**正本:** 本 GitHub モノレポの `packages/explore` と本ドキュメント  
**レガシー:** 旧 `.grok.me` Module1（WRECKLINE プレビュー）は **練習用／退役**。URL・Export をソース正本にしない。ゲームプレイ意図のみ参照可。

## 1. ひとことで

隊長は直接操作、僚機は **方針（スタンス）** で動く。回収完了後は自動で帯同に戻り、哨戒は拠点まわりを巡回し、遊撃は地点指定なしの自律攻撃。コンテナは探索で見つかるまで不明。画面外の僚機にも命令でき、画面外戦闘は戦報ログに出る。

---

## 2. 僚機方針（policies）

| ID | 表示 | 意図 | 地点 UI |
|---|---|---|---|
| `escort` | 帯同 | 隊長の左右後方にフォーメーション追従。近接脅威には反応射撃 | 不要（即時適用） |
| `patrol` | 哨戒 | **目標（ウェイポイント）または隊長** を中心に軌道／セクター掃討。直線で変な点へ飛んでから目的地、という挙動にしない | 任意（省略時は隊長周辺） |
| `recover` | 回収 | 発見済みコンテナへ向かいチャネル回収。完了後は **自動で帯同** | 省略時は最寄り発見コンテナ |
| `raid` | 遊撃 | 敵へ自律接近・交戦。弾薬浪費寄りでよい | **禁止**（クリック目標なし） |

### 2.1 回収 → 自動帯同

回収チャネルが完了した僚機は、同じティックで:

1. `stance = escort`
2. `waypoint = null`
3. 戦術ログに「回収完了 → 帯同」を残す

プレイヤーが再指示するまで帯同を維持する。

### 2.2 哨戒の一貫性

- 中心 = `waypoint ?? leader.pos`
- 移動目標は中心まわりの **軌道点**（角度を進める）。到達のたびに次の軌道点へ
- 交戦レンジ内の敵には一時的に反応してよいが、哨戒中心から大きく離脱し続けない

### 2.3 遊撃（地点指定なし）

- 命令パネル／ラジアルで遊撃を選んだ瞬間に適用
- マップクリックで遊撃地点を取らない
- AI は視界／広域で最寄り生存敵を狩り、敵なし時は隊長周辺をうろつく

---

## 3. 発見フォグ（コンテナ）

- ワールドにコンテナは最初から存在するが、**隊長または僚機の視界に入るまで位置不明**
- UI: 未発見はマーカーなし（または「未知信号」程度の曖昧表示は任意）。発見後に確定アイコン
- 回収命令の自動ターゲットは **発見済み** のみ

---

## 4. オフスクリーン指揮

- 僚機がカメラ外でも、常時表示の僚機パネルから方針を出せる（召還／帯同／哨戒／回収／遊撃）
- 「召還」= 帯同のエイリアス（隊長へ戻れ）
- マップ上の長押しラジアルは任意。v0 ではパネル命令で足りる

---

## 5. 画面外戦闘 → 戦報

- 戦闘イベント（与ダメージ／撃破／被弾）の発生位置がビューポート外のとき、**戦報フィード**へ要約行を追加
- 画面内は既存の軽いログ／エフェクトでよい
- フィードは新しい行が上（または下）に積み、直近 N 行を保持

例: `戦報: 僚機A が敵を撃破（北東・画面外）`

## 8. 受け入れ（Behavior v0）

1. 回収完了後、当該僚機の方針が自動で **帯同** になる（ログまたはデバッグ表示で確認可）
2. 哨戒中の移動目標が中心周辺の軌道上にあり、意味のない単発直線ワープに見えない
3. 遊撃適用にマップクリック／地点指定が不要。適用直後から敵探索・交戦する
4. 僚機が画面外でもパネルから命令でき、スタンスが実際に変わる
5. 未発見コンテナはマップ上に確定位置を出さない。発見後に表示・回収対象になる
6. 画面外で戦闘が起きると戦報フィードに行が増える
7. `npm run typecheck` / explore selftest が通る。`npm run dev:explore` で垂直スライスが動く
