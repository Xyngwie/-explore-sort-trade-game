## 1. Overview

`RESTORE` の回路復元を、ひとつのパズル画面だけではなく、生活・社会・前線・宇宙を接続する **世界アイテムの起点** として眺める与太話である。

- 日常の大半は flawed board であり、完全な解を持たない／壊れている／意図的に矛盾している。
- それでも、プレイヤーは部分解や調整によって回路を動かし、現場の出力を引き上げられる。
- ごく稀な大盤の perfect solution は、通常の報酬ではなく、世界の階層を一段上へ接続する特異点になる。
- したがって「完全に解けたか」と「未完成でも名機として働くか」は、同じ尺度ではない。

この文書でいう「パラドックス」は、**完全性が稀であるほど価値を持つ一方、未完成品の調整にも現実の価値がある**というねじれを指す。実装を要求する言葉ではない。

## 2. Scale layers 1–5 と、回路という特異点

ここでは、既存の Module 1–5 を、プレイヤーが触れるスケールの層として仮置きする。番号は実装順や依存関係を意味しない。

| 層 | 仮のスケール | 世界で扱うもの |
|---|---|---|
| 1 | 個体・出撃 | 一人の操縦者、機体、回収、摩耗。目の前の成果を持ち帰る層。 |
| 2 | 日常の加工 | sort、精製、修理、反復作業。薄利でも回数が社会を支える層。 |
| 3 | ハブ・艦隊・交換 | trade、在庫、修理、取引、役割分担。人と機体の関係が束になる層。 |
| 4 | 前線・地域 | invade / front、ルート、密度、危険域。どこで生産・回収するかを決める層。 |
| 5 | 回路・文明・宇宙 | restore、完全盤、希少な成果。下層の営みを上層の装置へ変換する層。 |

### 回路はスケールの特異点

回路は層 5 に置かれるが、盤面の一つひとつの辺は層 1 の手作業にまで分解できる。局所的な線の選択が、盤全体のループ、機体の出力、ひいては世界の接続を決める。この **小さな操作と巨大な結果の接続点** を、ここでは回路の特異点（singularity）と呼ぶ。

回路の価値は、常に「大きいほど正しい」ではない。小さな盤を完全に仕上げる職人、壊れた大盤を実用域まで調整する整備者、完成品を社会に配るハブが、それぞれ別の価値を持つ。

### 社会エコシステムの下層／上層

- **下層:** 回収屋、sorter、運搬屋、修理班、盤を読む職人、未完成回路を実用品にする現場。毎日の flawed board と向き合い、出力を少しずつ積み上げる。
- **上層:** 完全盤を保有するハブ、前線を動かす組織、文明規模の設備、そして top-tier の cosmos war。完全回路は上層の象徴になるが、その稼働は下層の職人と反復作業に依存する。

この上下は身分の優劣を確定する設定ではない。上層の戦争を成立させるのは、下層が作る部品・調整・物流である、という依存関係の比喩である。

### Module 5 artifact から見える自動化パラダイム

Module 5 の artifact（回路／Perfect Circuit）は、何でも自動化してプレイヤーの仕事を消す装置ではなく、**希少な理解と反復作業を分離する自動化** の象徴になるかもしれない。

1. 人は盤を読み、矛盾を見抜き、完全盤を稀に成立させる。これは職人性として残る。
2. その成果を回路 artifact に封じ、sort・修理・物流などの反復部分を下層で増幅する。
3. 自動化が進んでも、完全盤は稀であり、未完成盤を使いこなす職人の価値は消えない。
4. 上層の宇宙規模の設備は、下層の判断・調整・保守を吸い上げて初めて動く。

これは実際の自動化機能や NPC 方針を指定するものではない。Module 5 の artifact を、ゲーム内の「自動化とは人間の判断をなくすことではなく、判断を希少資源として増幅すること」という比喩に読むためのメモである。

## 3. Slitherlink mechanics（与太話上の得点・出力）

ここでのルールは、`RESTORE_V0.md` の薄いスタブを置き換えない。将来もし本編を考えるなら、次のようなねじれを持たせたい、という仮説である。

### 稀な大盤の perfect solution

- 大きな盤ほど、全数字を満たす単一ループの **perfect solution** は稀になる。
- perfect は「盤を埋めた」だけではなく、すべての数字を満たし、回路全体として正しく閉じていることを指す。
- 稀少性そのものが世界アイテムとしての価値を作る。通常の flawed board と同じ頻度・同じ報酬にしない。

### 数字を満たした数でスコアを測る

盤面の各数字について、隣接する線の本数が数字と一致していれば、その数字を満たしたものとして数える。完全解でなくても、満たした数字の数は「どれだけ回路を読めたか」「どれだけ出力へ寄与したか」の粗い指標になる。

### 複数ループのペナルティ

複数のループができた場合は、ループごとに、そのループが含む／支える **満たした数字の数** をスコア化する。そして最終スコアは、複数ループのうち **満たした数字が最も少ないループのスコア** とする。

つまり、良いループだけを足し合わせて褒めるのではなく、最も弱いループが全体の出力を制限する。これが multi-loop penalty であり、全体を一つの回路として整える動機になる。

### 未完成盤を高出力の名機へ調律する

完全解でない盤も、無価値とは限らない。矛盾を抱えたままでも、線の選び方・ループの切り分け・現場での調整によって、安定した高出力を引き出せる場合がある。そのような未完成の回路を、プレイヤーが **高出力の名機** に仕立てる余地を残したい。

ここでは、perfect solution が「世界を開く希少な完成品」、調律された flawed board が「現場で信頼される名機」である。両者を同一の完全度ランキングだけで潰さないことが、このパラドックスの要点である。

## 4. Perfect Circuit world item

### 0-cell の扱い

**0-cell は、回路が fully perfect になった場合にだけカウントする。** 部分解、Bypass、実用域まで調律された flawed board は、どれほど高出力でも 0-cell の数には加えない。

ここでの 0-cell は、Perfect Circuit が世界に存在したことを記録する最小単位であり、通常の成果スコアや出力値とは別の希少資源である。実際の型、保存形式、付与タイミングは未定義で、実装を示唆しない。

### 盤面サイズの解放

現在のサイズの盤を perfect にできたときだけ、次に大きいサイズの盤を解放する。未完成盤を何枚動かしても、完全盤を一度成立させるまでは次のサイズへ進まない。

この条件は、周回数や資材量ではなく、**そのサイズの構造を完全に理解した証拠** を進行条件にする、という願望である。大盤の perfect solution が稀であることと、サイズ解放の重さを結びつける。

### Top-tier cosmos war と下層の職人

最上位の cosmos war は、上層の勢力だけで完結しない。完全回路を数え、次のサイズを開き、宇宙規模の設備を維持できるのは、下層で flawed board を読み、調律し、部品を作り、回路を保守する puzzle craftsmen がいるからである。

- perfect circuit は上層の戦略資源になる。
- 名機化された未完成盤は、下層の生活と前線を支える。
- 下層の職人がいなければ、上層の完全盤も宇宙戦争も継続できない。

この依存関係が、回路パズルを単なる報酬画面ではなく、社会エコシステムの中核として見るための「cosmos aspiration」である。なお、cosmos war、0-cell、サイズ解放、職人の役割はいずれも未実装であり、V0 の受入対象ではない。
