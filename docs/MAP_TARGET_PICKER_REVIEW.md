# 密集するマップ操作対象

#319公開main d093141で、設置盾と近傍の地面盾のタップ範囲が重なると、設置盾の撤去パネルだけが表示される状態を再現した。第三者手順と公開調査は独立Draft #320。

## 修正範囲

- 既存の画面タップ範囲（24画面px相当）を使い、見えている設置盾・地面盾グループ・剥離可能な残骸・選択可能な僚機を列挙する。
- 複数候補のときだけ「対象を選択」を表示。「この地点へ移動」と「取消」も選べる。
- 設置盾→既存撤去パネル、地面盾→既存回収候補、僚機→その機体の既存個別指示、残骸盾→既存剥離開始条件へ接続する。距離・回路・作業時間は既存の判定を通す。
- 選択時に対象がまだ存在するか再確認する。同じ座標の複数残骸は、選択したIDを剥離関数に渡して取り違えない。
- 単独対象の従来タップを維持。「残骸盾」の明示的な次タップと僚機などのpending指示は候補UIを経由しない。
- 物理当たり判定・防御角・60x8壁・作業時間・保存型/契約・盾ID/小数HP・通常セーブ書戻しは変更しない。

`mapTargets.selftest.ts`は複数候補、単独/空欄、回路条件、HTML escape、World非変更、同座標残骸のID指定を確認する。
