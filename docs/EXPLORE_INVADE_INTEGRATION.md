### 探索の地図

`packages/explore/src/game/balance.ts`

- 地図の大きさは `BALANCE.worldW` 1400、`worldH` 1000
- 出現点 `SPAWN_POINT` は (700, 500)。地図の中心（`packages/explore/src/facing.selftest.ts` が中心であることを見ている）
- コンテナは `fieldContainerCount` 20。置き方は `packages/explore/src/game/world.ts` の `placeContainers`（1400×1000 の中の目印と、5 列×4 行の格子）
- 敵の数は `threatFromDensity` と `threatFromEngage` が決める。返すのは数と、出現の距離・速さ・HP の倍率である。マスの座標は位置に使わない。`enemyCells` は件数だけを数える
- 敵の位置は `world.ts` の `placeEnemies` が、出現点の周りの輪に置く
- 段位の倍率は `packages/shared/src/invade-rank.ts` の `rankEnemyMultiplier`（1.01 の段乗）。`world.ts` の `createWorld` が、敵の HP と `enemyDamage` に掛ける。出撃につき一つ

### 侵略の盤

`packages/shared/src/front-board.ts`

- 一辺 25（`AOI_HALF` 12、座標 −12…+12、`BOARD_SPAN` 25）。決定 2 の盤全体 35000×25000 は、この 25 に今の 1400 と 1000 を掛けた数である
- 地雷の確率は [`INVADE_V0.md`](./INVADE_V0.md) §8.7。コードは `mineProbabilityAtDistance`。拠点からのチェビシェフ距離 `d` について、`P = 0.05 + min(1, d/10) × 0.20`（`MIN_MINE_P` 0.05、`MAX_MINE_P` 0.25、`SECTOR_FRONT_DISTANCE` 10）。`d` が 0（HQ）と、`d` が 12 以上（壁。`SECTOR_WALL_DISTANCE`）は地雷にしない
- 開いた地雷で、強制戦闘のロックが外れているとき（`hitMine === false`）、表示は「済」（`cellGlyph`）。ロック中は「✕」

盤の読み書きは `packages/invade/src/hub-persist.ts`（`frontProgress`）。段位は `packages/shared/src/invade-rank.ts`。初クリアは `packages/shared/src/first-clear.ts`。強制戦闘のロックは `packages/invade/src/forced-combat.ts`。

### 出撃へ渡すキー

[`INVADE_V0.md`](./INVADE_V0.md) §8.5。invade から explore へ渡す URL のキーは `sectorX`、`sectorY`、`density`、`intelFlags`、`engage`、`enemyCells`。定数は `packages/shared/src/constants.ts` の `HANDOFF_QUERY_KEYS.invadeToExplore`（ほかに `invadeRank` と `neighborCount`）。

直接出撃は `packages/explore/src/game/directFieldEntry.ts`。保存してある盤の seed を使い、HQ のマス (0, 0) へ出す（`sectorX=0`、`sectorY=0`、`density=0`）。開いたマスとマークは変えない。

出撃の場所は、そのマス一つである（`packages/explore/src/game/lostMechs.ts` の `sortieLocationFor`。`frontSeed` と `cell`）。

### セーブ

保存キーは `wreckline.hubSave.v3`（`packages/shared/src/constants.ts` の `HUB_SAVE_STORAGE_KEY`）。

関係する欄は、すべてこのキーの中にある。

- `frontProgress`（盤の seed、開いたマス、マーク、焦点、`hitMine`）
- `fieldCells`（`packages/shared/src/field-cell-state.ts`。`frontSeed` と `cell`）
- `fieldDrops`（`packages/shared/src/hub-save.ts`。`frontSeed` と `cell`。探索の中の座標は持たない）
- `lostMechs`（同じファイル。任意の `frontSeed` と `cell`。`pos` は探索の座標）
- `invadeRank`
- `firstInvadeClear`

`fieldCells` の地面と残骸の `pos` も、探索の座標である。

出撃の勝敗は、盤の開いたマスとマークを書き戻さない。強制戦闘が終わると `clearPendingForcedCombat` が `frontProgress.hitMine` だけを消す。開いた地雷の「済」は、このロック解除の表示である。倒したかどうかとは別で、失敗や中断でもロックは外れる。マークしたマスへ任意で出て倒しても、そのマスが開いていなければ「済」にはならない。

中隊長 7500、僚機の小隊長 1500（`BALANCE.commandRangeCaptain` / `commandRangePlatoonLeader`）。#365 で入れた。今の 1400×1000 では 7500 が地図の全体を覆う。この二つの半径は、ここにある広い地図を見越して選んであり、変えない。正本は [`AUTONOMOUS_LEARNING_V0.md`](./AUTONOMOUS_LEARNING_V0.md) の「小隊長の通信と分担」と、[`MECH_WORLD_BUILDING_DESIGN.md`](./MECH_WORLD_BUILDING_DESIGN.md) §6。

### 段階 1（実装済み・PR #369）

状態：実装済み（PR #369。基準は main `5f34a24` 以降）。見た目も動きも、既定の 1400×1000 では変えていない。決定 13 の配置は、この段では作らない。

地図の大きさは `createWorld(boot, { worldW?, worldH? })` で渡す。省略した軸、および有限な正の数でない値は、`BALANCE` の 1400 と 1000。値は、その出撃の `world.balance` のコピーにだけ書く。大域の `BALANCE` は変えない。

### 段階 2（実装済み・PR #370）

状態：実装済み（PR #370。基準は main `e9a725e` 以降）。純関数とテストだけ。ゲームの動きは変えていない。explore の `createWorld`、sim、カメラ、出現点、コンテナ、敵、セーブ、invade、画面は触っていない。

決定 14 と決定 15。コードは `packages/shared/src/cell-world.ts`（`index.ts` から出す）。関数は `cellCenterToWorld(sx, sy)`、`cellBoundsInWorld(sx, sy)`、`worldToCell(x, y)`。1 マスの大きさは `CELL_WORLD_W` 1400 と `CELL_WORLD_H` 1000。盤の半径は `front-board.ts` の `AOI_HALF`（12）をそのまま使う。1400、1000、12 は、この変換ではそれぞれ一箇所だけである。

マス `(sx, sy)` の中心は `(sx * 1400, sy * 1000)`。範囲は半開区間で、x が `[sx * 1400 − 700, sx * 1400 + 700)`、y が `[sy * 1000 − 500, sy * 1000 + 500)`。左と上の端はそのマス、右と下の端は隣のマス。

`cellCenterToWorld` と `cellBoundsInWorld` は、この式だけを返す。マスが盤の中にあるかは見ない。

`worldToCell` は、有限でない座標と、入るマスの `sx` または `sy` が −12…+12 の外になる座標を `null`（盤の外）で返す。盤が覆う範囲は x が `[−17500, +17500)`、y が `[−12500, +12500)`。決定 14 の「x が −17500…+17500、y が −12500…+12500」は、25 マス × 1400 と 1000 の幅（35000×25000）を HQ 中心に置いた両端である。半開区間なので、右端の x = +17500 と下端の y = +12500 は盤の外（+13 のマスの左・上の端であり、そのマスは無い）。左端の x = −17500 と上端の y = −12500 はマス (−12, −12) に入る。

## 段階 3 の解釈

決定の文を、コードが一つの動きになるように読んだところ。新しい選択にはしていない。

- マスの距離は、盤と同じチェビシェフ距離。
- 遊べる範囲は、拠点からの距離が 12 未満のマス。世界では x が [-16100, 16100)、y が [-11500, 11500)。右と下の境目は壁マス側（半開区間）。機体の中心は、その境目から 20（今まで端に置いていた余白）だけ内側。境目ちょうどは壁に入る。
- 安全と分かっている空白地帯は、開いていて、地雷でなく、壁でもないマス。数字のマスと HQ を含む。旗が立っていて開いていないマスは、地雷なら敵 2 とコンテナ 1。地雷でなければ何も置かない。開いていない、地雷でないマスも何も置かない。
- 開封済みの地雷（「済」と「✕」）にも、この段では敵 2 とコンテナ 1 を置く。倒したマスを空にするのは段階 4。
- 安全マスのコンテナは、`wideHash(seed, sx, sy, 0)` を 10 で割った余りが 0 のマスに 1 個。同じ frontSeed と、同じ開封・旗なら、同じ配置。割合の期待は 10 分の 1。マスの中の位置も同じハッシュ。中心から 140 以上離し、開始位置と重ねない。
- 敵のホームは、配置した地雷マス。自分の移動では隣マス（距離 1）より外へ出ない。見つけた相手がその外なら、自分のマスの中心へ戻る。すでに隣より外にいる敵（動き始める前に置かれた位置）は、そのマスをホームにする。地図を横断しては戻らない。回収するコンテナも、そのとき歩ける範囲の中だけから選ぶ。外にしか無いときは回収しない。
- 隊長から距離 2 より遠い敵は、移動も射撃も回さない。
- 霧は、盤の全セルを毎フレームは見ない。味方の視界のまわりだけ更新し、見たセルだけ覚える。まだ開いていないマスは濃い霧のまま（決定 21）。盤で開いているマスは、出撃の開始時に一度だけ霧を晴らす（決定 25）。その後の戻りは、今の霧の記憶と同じである。
- 回路が「まだ見ていない霧」へ進むときは、機体のまわり（視界の数倍）だけを探す。
- `createWorld` の `worldW` / `worldH` は、地図の大きさを変えない。壁や盤の外の sector からは出撃せず、(0, 0) から始める。
- 敵の数は盤で決まる。機体の HP は、今までどおり段位の倍率だけ掛ける。密度とエンゲージの `enemyHpMul` は脅威の値として残るが、機体 HP には掛けない（段階 3 の前の `placeEnemies` も掛けていなかった）。速さの倍率は `world.balance.enemySpeed` に入る。
- 遮蔽物は 10 個のまま、壁の内側全体に散らす。置き去りの散らしも、同じ範囲。
- 古い探索の座標（`lostMechs.pos`、`fieldCells` の地面と残骸）は、この段では広い地図の座標へ移さない。有限で、遊べる範囲の中なら、その数値のまま置く。今の 0…1400×0…1000 は、HQ の右下付近に入り、壁ではない。非数、壁の中、範囲の外は、読み込んだときの表示位置だけ壁の内側へ寄せ、動けなくしない。セーブを一括では書き換えない。進行中のチェックポイントに `minX` が無いときは、保存された 0…worldW のまま動かす。移しは段階 4（決定 34）。

## 段階 4 の解釈

決定の文を、コードが一つの動きになるように読んだところ。決定 35〜37 は神宮決定 2026-11-13 で、すべて A。

- セキュアなマスは、盤で開いているマス（数字、HQ、済、✕）と、この出撃で敵 2 体を倒した地雷、味方が入って開いた地雷でないマス。
- 済にする敵は、そのマスに最初に置いた 2 体だけ。追いかけて入った敵は数えない。2 体が両方とも倒れたティックで、そのマスを opened に足す。
- 既存の済は、開いた地雷かつ `hitMine` が false のときの字形である。倒した瞬間に `hitMine` を false にする。盤の旗は一つなので、そのとき開いているほかの地雷も済になる（決定 37）。
- 書いた内容は、その出撃の `frontProgress` にすぐ残す。全滅で出撃が終わっても消さない。
- 地雷でないマスは、生きている味方の中心が入ったそのマスだけを開く。旗が立っていれば外す。数字が 0 でも隣は開かない（決定 35）。地雷マスは、入っただけでは開かない。
- この出撃でセキュアにしたマスの霧は、その出撃の視界の更新でも書かない。次の出撃の開始時に、決定 25 と同じく、開いているマスとして一度で晴らす。
- 見張りは、生きている敵のいるマスがセキュアなとき、そのマスの中だけ。出撃の地図ではその敵が見える。大マップの印は `{ sx, sy }` だけで、世界座標は持たない。`frontProgress.enemyHere` に置く（最上位キーではない）。印は出撃後も残り、次の出撃の開始時に、そのときセキュアなマスにいる敵だけで置き直す（決定 36）。
- 済と ✕ の地雷には、敵もコンテナも置かない。開いていない地雷は、敵 2 体とコンテナ 1 個のまま。
- 印 `wide: true` の無い座標で、x が 0…1400、y が 0…1000（両端を含む）のものを、x−700、y−500 にする。印は `lostMechs.pos` と、`fieldCells` の地面と残骸の位置に付ける。新しく書く世界座標にも印を付ける。印があると、もう移さない。非数の位置はこれまでどおり捨てる。遊べる範囲の外は、表示のときだけ壁の内側へ寄せ、セーブの数値は寄せない。バリケードの位置は移さない。
